API 2º Semestre (Fatec) - Sistema de Ordens de Serviço ALTAVE

Instituição parceira:

ALTAVE.


Sobre:

Projeto acadêmico de desenvolvimento web realizado em parceria com a empresa ALTAVE, com o objetivo de desenvolver um sistema para gerenciamento e acompanhamento de Ordens de Serviço (OS). A plataforma busca otimizar a comunicação entre setores, organizar solicitações de novos produtos e manutenções, além de proporcionar maior controle sobre as etapas de execução, responsáveis e prioridades dos serviços. O desenvolvimento utiliza metodologias ágeis, com organização baseada no Scrum e entregas divididas em Sprints.


Contribuições Pessoais:

Atuei como integrante da equipe de desenvolvimento (Dev Team), participando da implementação das funcionalidades do sistema. Contribuí principalmente no desenvolvimento frontend, na construção de interfaces e organização dos componentes da aplicação, buscando proporcionar uma experiência de uso intuitiva e facilitar a visualização e o gerenciamento das informações. Também participei da organização das atividades e do acompanhamento das entregas durante as Sprints, utilizando ferramentas de versionamento e gerenciamento do projeto.


Hard Skills (Habilidades Técnicas):

Desenvolvimento frontend com React, TypeScript, HTML e CSS, utilização de Vite e Tailwind CSS, integração com serviços backend, conceitos de APIs REST, banco de dados MySQL, versionamento de código com Git e GitHub e organização de tarefas com Jira. Aplicação de conceitos de desenvolvimento de software e metodologia ágil Scrum.


Soft Skills (Habilidades Comportamentais):

Trabalho em equipe, comunicação, colaboração, organização, proatividade, resolução de problemas e adaptação a mudanças.


Tecnologias utilizadas:

GitHub - VS Code - React - TypeScript - HTML - CSS - Tailwind CSS - Node.js - Express - MySQL - Vite - Jira - Git.
