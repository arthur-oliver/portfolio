Sistema de Ordens de Serviço

Empresa parceira: ALTAVE

Problema

A necessidade de registrar, priorizar e acompanhar as ordens de serviço trocadas entre os setores da empresa — como solicitações de novos produtos e de manutenções —, com controle claro sobre as etapas de execução, os responsáveis e as prioridades de cada demanda.

Solução desenvolvida

Sistema web para gerenciamento de Ordens de Serviço (OS) que centraliza as solicitações, permite acompanhar o andamento de cada etapa e define responsáveis e prioridades, melhorando a comunicação entre os setores.

Contribuições pessoais

Atuei no time de desenvolvimento, principalmente no front-end: construção de interfaces e organização dos componentes da aplicação, buscando uma experiência de uso intuitiva. Também participei da organização das atividades e do acompanhamento das entregas durante as Sprints.

Hard skills

Desenvolvimento front-end com React e TypeScript, estilização com Tailwind CSS, uso do Vite, integração com APIs REST, noções de banco de dados MySQL e versionamento com Git e GitHub.

Soft skills

Trabalho em equipe, comunicação, colaboração, organização, proatividade, resolução de problemas e adaptação a mudanças de requisitos.

Tecnologias utilizadas

  • TypeScript
  • Tailwind CSS
  • Vite
  • Node.js
  • Express

Análise de Comércio Exterior de SP

Empresa parceira: Fatec São José dos Campos (cliente interno)

Problema

Os dados públicos de importações e exportações do estado de São Paulo são volumosos e estão dispersos em diferentes tabelas, o que dificulta comparar períodos, produtos, valor agregado e países parceiros e, consequentemente, identificar tendências que apoiem análises do setor de logística.

Solução desenvolvida

Site para análise das importações e exportações de SP, que organiza os dados por ano, valor agregado e relações exteriores e os apresenta por meio de gráficos, facilitando a leitura e a comparação das informações.

Contribuições pessoais

Atuei como Scrum Master, priorizando a agilidade nas entregas e removendo impedimentos da equipe. Também apoiei a pesquisa dos dados, criei os gráficos em Python no Google Colab, desenvolvi parte do HTML e CSS, montei os slides da apresentação e organizei o GitHub e o Jira do projeto.

Hard skills

Manipulação de dados e criação de gráficos com Python, estruturação de páginas com HTML e CSS, versionamento com Git e GitHub e gestão de backlog com Jira dentro do framework Scrum.

Soft skills

Liderança, proatividade, comunicação e adaptação ao alternar entre os papéis de Scrum Master e integrante do time de desenvolvimento ao longo das Sprints.

Tecnologias utilizadas

  • Python
  • Flask
  • HTML
  • CSS

  • Git
  • GitHub

PACKUP – Gerenciamento de Estoque Mobile

Instituição: Instituto IDEIA

Problema

Empresas de diferentes segmentos precisam controlar entradas, saídas e quantidades de produtos em estoque. Sem um controle prático e acessível, aumentam os erros de contagem, as faltas e os excessos de mercadoria, prejudicando a gestão do negócio.

Contribuições pessoais

Soft skills

Liderança, organização, proatividade, comunicação, resiliência, criatividade e adaptação.

Avaliação individual · AV3

Greencode – Logística Reversa de Resíduos Eletrônicos

Instituição: Fatec São José dos Campos · Prof. Dr. Gerson Penha

Problema

Empresas que recebem equipamentos eletrônicos descartados precisam acompanhar cada item desde o recebimento do lote até a triagem, o desmonte e a baixa definitiva, com rastreabilidade e auditoria. Além disso, precisam de indicadores para avaliar a eficiência da operação e a rentabilidade, e de uma forma segura de compartilhar essas informações com as organizações parceiras que enviam os resíduos.

Solução desenvolvida

API REST com portal web que controla organizações, contratos, lotes e equipamentos, registrando cada movimentação com responsável e justificativa. Na AV3, ganhou uma camada analítica (eficiência operacional, rentabilidade por tipo de equipamento e vida útil restante por regressão linear), uma API pública para parceiros com chave de API e relatórios gerados de forma assíncrona em fila.

Contribuições pessoais

Projeto individual: desenvolvi todas as etapas, evoluindo a base das avaliações anteriores (AV1 e AV2). Modelei o banco de dados, implementei a API em camadas (rotas, controllers, serviços e repositórios), a autenticação com cinco papéis e superusuário único, as análises estatísticas agendadas, a fila de relatórios com retry, o portal web em React e a documentação técnica, além dos testes automatizados.

Hard skills

Arquitetura de APIs REST em camadas com Node.js, TypeScript e Fastify; modelagem relacional com Prisma e MySQL; transações, versionamento otimista e soft delete; autenticação JWT e chaves de API com hash; processamento assíncrono; estatística aplicada; documentação com Swagger e testes com Vitest.

Soft skills

Autonomia, organização, gestão do próprio tempo, pensamento crítico nas decisões de arquitetura e comunicação escrita na documentação para outros desenvolvedores e para o professor.

Tecnologias utilizadas

  • Node.js
  • TypeScript
  • Fastify
  • Prisma
  • MySQL
  • JWT
  • Swagger
  • Vitest
  • React
  • Tailwind CSS
  • Vite
  • Git
  • GitHub
